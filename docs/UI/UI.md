## 设计理念

QuickMemes 是一款面向桌面用户的**本地梗图管理与快速取用工具**。UI 设计追求以下核心目标：

- **高频效率优先**：双击即复制、拖拽即归类、快捷键即调用
- **海量数据无感**：虚拟瀑布流渲染，无论图库数量级如何，滚动始终丝滑
- **原生级视觉体验**：磨砂玻璃（Glassmorphism）+ 大圆角设计语言，默认跟随系统主题

### 全局约束

| 约束项         | 值                                        |
| -------------- | ----------------------------------------- |
| 图库数量       | 单一全局默认图库，不支持多库切换          |
| 布局架构       | CSS Grid/Flex 受控布局 + `react-virtuoso` |
| 视觉风格       | 磨砂玻璃 + 大圆角                         |
| 默认主题       | 跟随系统（亮色/暗色自适应）               |
| 长列表渲染策略 | 虚拟瀑布流 / 虚拟网格                     |
