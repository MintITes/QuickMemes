## 设置模态框

> **触发**：点击顶栏设置按钮 或 `Ctrl+,`  
> **类型**：居中模态对话框（Modal），背后显示半透明遮罩层  
> **关闭**：点击右上角 × / 点击遮罩层 / 按 Esc

### 布局结构

```
┌──────────────────────────────────────────────┐
│  ✕                     设置                   │
├────────────┬─────────────────────────────────┤
│            │                                 │
│  常规      │   主题                          │
│  存储      │   ○ 跟随系统  ● 亮色  ○ 暗色   │
│  OCR       │                                 │
│  AI 视觉   │   语言                          │
│  快捷键    │   [简体中文          ▾]         │
│  关于      │                                 │
│            │   启动时检查更新                 │
│            │   [  ●━━━━ ON ]                 │
│            │                                 │
├────────────┴─────────────────────────────────┤
│                              [取消]  [保存]  │
└──────────────────────────────────────────────┘
```

### 左侧分类导航

| 分类    | 包含的设置项                    |
| ------- | ------------------------------- |
| 常规    | 主题选择、语言、启动行为        |
| 存储    | 存储路径、缩略图设置、备份设置  |
| OCR     | OCR 引擎选择、云端 OCR API 配置 |
| AI 视觉 | API 密钥、模型选择、超时与重试  |
| 快捷键  | 全局快捷键绑定配置              |
| 关于    | 版本信息、开源许可证            |

### 实时预览 (Live Preview) [NEW]

在“存储”、“常规”和“外观”设置面板的右下方，常驻一个 **Demo 预览卡片**。
*   **功能**：当用户调节“毛玻璃模糊级别”、“圆角半径”、“强调色”或“卡片间距”时，Demo 卡片实时响应变化。
*   **目的**：让用户在保存设置前直观看到视觉调整的效果，避免重复打开/关闭设置窗口。

### 设置项控件风格

所有设置控件统一采用现代化风格：

| 控件类型      | 规格                                                                  |
| ------------- | --------------------------------------------------------------------- |
| 开关 (Toggle) | 滑动式开关，ON 和 OFF 状态有**明显的颜色差异**（ON=强调色，OFF=灰色） |
| 下拉选择      | 圆角下拉框，点击展开选项列表                                          |
| 多选展开框    | 点击后展开一个内嵌小面板，内含复选框列表                              |
| 文本输入      | 圆角输入框，带占位提示                                                |
| 路径选择      | 输入框 + 右侧"浏览"按钮（弹出系统文件夹选择器）                       |

## 灯箱预览

> **触发**：右键菜单中选择"查看详细" / 按 `Enter` / 双击三点按钮  
> **类型**：全屏覆盖的灯箱层，背景深色半透明遮罩  
> **关闭**：点击遮罩空白区域 / 按 `Esc` / 点击关闭按钮

### 布局结构

```
┌──────────────────────────────────────────────────────────────┐
│                                                        [✕]  │
│                                                              │
│    [◀]          ┌─────────────────────┐          [▶]        │
│                 │                     │                      │
│                 │                     │                      │
│                 │     梗图大图展示     │                      │
│                 │   (可放大/缩小)      │                      │
│                 │                     │                      │
│                 │                     │                      │
│                 └─────────────────────┘                      │
│                                                              │
│    [🔍+ 放大] [🔍- 缩小] [↺ 原始尺寸]                       │
│                                                              │
│    标签: [标签A ×] [标签B ×] [+ 添加标签]                    │
│                                                              │
│    [📋 复制到剪贴板]  [💾 导出]  [🏷️ 编辑标签]              │
└──────────────────────────────────────────────────────────────┘
```

### 沉浸式视觉

灯箱背景遮罩将启用**智能取色 (Adaptive Tint)**：
*   背景色将根据当前梗图的主色进行微弱染色（Tint），保持 0.1-0.2 的不透明度，使大图展示更加沉浸且不显呆板。

### 功能列表

| 功能         | 说明                                                |
| ------------ | --------------------------------------------------- |
| 图片展示     | 居中显示高分辨率大图                                |
| 缩放控制     | 支持 `+` / `-` 按钮和滚轮缩放，`0` 恢复原始尺寸     |
| 左右切换     | `◀` `▶` 按钮或方向键切换上一张/下一张               |
| 标签展示     | 显示当前梗图所有标签（TagChip），支持直接删除或添加 |
| 复制到剪贴板 | 快捷按钮，点击后弹出 Toast 确认                     |
| 导出         | 快捷按钮，弹出另存为对话框                          |
| 编辑标签     | 快捷按钮，展开标签编辑区                            |

### 快捷键

| 快捷键    | 操作              |
| --------- | ----------------- |
| `←` / `→` | 切换上一张/下一张 |
| `+` / `-` | 放大/缩小         |
| `0`       | 恢复原始尺寸      |
| `Ctrl+C`  | 复制到剪贴板      |
| `Esc`     | 关闭灯箱          |

## 快捷导入窗口

> **触发**：点击 ⊕ 下拉菜单中的"快捷导入" / 系统拖拽文件到窗口时自动弹出  
> **类型**：居中模态窗口  
> **关闭**：点击 × / Esc / 导入完成后自动关闭

### 布局结构

```
┌──────────────────────────────────────┐
│  快捷导入                        ✕   │
├──────────────────────────────────────┤
│                                      │
│     ┌────────────────────────┐       │
│     │                        │       │
│     │   📥 将文件拖到此处     │       │
│     │                        │       │
│     │   支持 PNG, JPG, GIF   │       │
│     │     WebP, BMP          │       │
│     │                        │       │
│     └────────────────────────┘       │
│                                      │
│          或  [选择文件]              │
│                                      │
└──────────────────────────────────────┘
```

### 交互状态

| 状态         | 视觉效果                                         |
| ------------ | ------------------------------------------------ |
| 默认         | 虚线边框的拖拽放置区，居中图标和提示文字         |
| 拖拽悬停     | 边框变为实线强调色，背景半透明高亮，图标放大     |
| 放置成功     | 短暂绿色闪烁反馈，之后开始后台导入               |
| 全局拖拽感知 | 从系统拖入文件时，此窗口自动弹出，即使之前未打开 |

## 通知面板

> **触发**：点击底部状态栏右侧的通知指示灯  
> **类型**：从底部右侧向上展开的浮动面板  
> **关闭**：点击面板外部 / 按 Esc

### 布局结构

```
                        ┌────────────────────────┐
                        │  通知              ✕   │
                        ├────────────────────────┤
                        │                        │
                        │  ℹ️ OCR 处理完成        │
                        │     12:30              │
                        │  ────────────────────  │
                        │  ⚠️ 导入部分失败        │
                        │     2 个文件格式不支持  │
                        │     12:28              │
                        │  ────────────────────  │
                        │  ❌ 后端连接中断         │
                        │     正在重连...        │
                        │     12:25              │
                        │                        │
                        ├────────────────────────┤
─────────────────┬──────┤            清除全部  🔴│
   底部状态栏    │      └────────────────────────┘
```

### 排序规则

通知从下到上按**严重等级**排序：

| 位置   | 等级         | 颜色 |
| ------ | ------------ | ---- |
| 最下方 | 错误 (Error) | 红色 |
| 中间   | 警告 (Warn)  | 黄色 |
| 最上方 | 信息 (Info)  | 蓝色 |

### 处理行为

- 点击某条通知可将其标记为已读或执行相关操作
- 处理完最下方（最严重）的通知后，上方通知向下滑动填补位置
- "清除全部"按钮一键清除所有通知
- 所有通知清除后，指示灯恢复为绿色

### 通知类型

| 通知内容     | 等级 |
| ------------ | ---- |
| 导入完成     | 信息 |
| OCR 处理完成 | 信息 |
| 导入部分失败 | 警告 |
| 后端连接中断 | 错误 |
| 数据库错误   | 错误 |

## 布局切换面板

> **触发**：点击顶栏布局切换按钮  
> **类型**：按钮正下方弹出的小型浮动面板  
> **关闭**：选择布局 / 点击外部 / 按 Esc

### 布局结构

2×2 排列的简约图示，每个图示直观展示对应的布局模式：

```
┌─────────────────────────────┐
│  ┌───────┐   ┌───────┐     │
│  │[█│░░│█]│   │[█│░░░░]│     │
│  └───────┘   └───────┘     │
│  左展+右展   左展+右隐     │
│                             │
│  ┌───────┐   ┌───────┐     │
│  │[▎░░│█]│   │[▎░░░░░]│     │
│  └───────┘   └───────┘     │
│  左折+右展   左折+右隐     │
└─────────────────────────────┘
```

- 当前激活的布局对应的图示有**强调色边框**
- 悬停其他图示时有半透明背景填充
- 点击即切换到对应布局

> **触发**：永久删除 / 清空回收站等破坏性操作  
> **类型**：居中模态对话框，背后显示遮罩

```
│               [取消]  [永久删除]      │

```

### 按钮样式

| 按钮       | 样式                                                     |
| ---------- | -------------------------------------------------------- |
| 取消       | 普通样式（无强调色），默认获取焦点                       |
| 破坏性操作 | 红色/警告色背景，明确提示危险性                          |
| 快捷键辅助 | 在按钮右侧用淡色文字标注对应按键（如：`Enter` 或 `Esc`） |

## 快捷键速查层 (Keymap Overlay) [NEW]

> **触发**：全局长按 `Ctrl` (> 1s) 或点击顶栏设置旁的小问号图标  
> **类型**：全屏透明遮罩 + 强磨砂质感 (Blur: 20px)  
> **目的**：通过视觉引导增强全键盘操作的可发现性。

### 布局结构

屏幕中央显示语义化排列的按键说明：

*   **[ 搜索 & 全局 ]**：`Ctrl+F` 搜索 / `Ctrl+,` 设置 / `Ctrl+V` 剪贴板导入
*   **[ 画廊浏览 ]**：`Arrows` 移动焦点 / `Enter` 预览 / `Space` 选中 / `Del` 回收站
*   **[ 视图控制 ]**：`Ctrl+滚轮` 缩放卡片与间距 / `Ctrl+B` 切换显示标签
*   **[ 魔法桶 ]**：`Tab` 合集管理（展开暂存层）

### 交互

*   **即用即走**：松开 `Ctrl` 键即消失，不产生点击阻断。

## 导出对话框

> **触发**：右键菜单"导出" / 批量导出  
> **类型**：系统原生另存为对话框（通过 Electron `saveFileDialog` 调用）

### 功能

| 功能     | 说明                                     |
| -------- | ---------------------------------------- |
| 文件名   | 默认使用原文件名，可修改                 |
| 格式选择 | 通过文件类型过滤器选择（原格式/PNG/JPG） |
| 保存路径 | 用户自由选择保存位置                     |
