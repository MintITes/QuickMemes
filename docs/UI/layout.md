## 布局概览

整个应用窗口被划分为 **5 个核心区域**，采用 CSS Grid / Flex 布局实现：

| 区域         | 位置   | 尺寸行为                     | 内容职责                |
| ------------ | ------ | ---------------------------- | ----------------------- |
| 顶部操作栏   | 最顶部 | 宽度撑满，高度固定           | Logo、搜索、工具按钮组  |
| 左侧导航栏   | 左侧   | 高度撑满中间，宽度可拖拽调整 | 分类导航、文件夹树      |
| 中间主区域   | 中心   | 自适应填充剩余空间           | 梗图画廊（虚拟列表）    |
| 右侧属性面板 | 右侧   | 高度撑满中间，宽度可拖拽调整 | 选中梗图详情、标签、OCR |
| 底部状态栏   | 最底部 | 宽度撑满，高度固定           | 统计信息、进度、通知灯  |

## 区域 1：顶部操作栏 (Header)

> **高度**：固定（不随窗口缩放变化）  
> **宽度**：撑满窗口  
> **不可编辑布局**：用户不能调整顶栏内部元素的排列方式

> **平台差异**：元素排列会根据操作系统（macOS vs Windows/Linux）自动适配。

### macOS 元素排列（从左到右）

| 序号 | 元素             | 说明                                                                        |
| ---- | ---------------- | --------------------------------------------------------------------------- |
| 1    | **窗口控制键**   | Mac 原生风格的红绿灯按钮，位于最左侧，**无需显示 Logo**                     |
| 2    | **全局搜索框**   | 玻璃质感长椭圆矩形。内部右侧嵌套一个**圆形凸起 ⊕ 按钮**，点击弹出导入主要项 |
| 3    | **布局切换按钮** | 图标按钮，点击后在下方弹出 2×2 布局预设选择浮窗                             |
| 4    | **主题切换按钮** | 图标按钮，切换亮色 / 暗色主题                                               |
| 5    | **设置按钮**     | 齿轮图标按钮，点击弹出居中设置模态框                                        |
| 6    | **用户头像**     | 圆形头像占位（V1 暂不实现点击功能）                                         |

### Windows / Linux 元素排列（从左到右）

| 序号 | 元素             | 说明                                                                        |
| ---- | ---------------- | --------------------------------------------------------------------------- |
| 1    | **软件 Logo**    | 位于最左侧，展示应用图标                                                    |
| 2    | **全局搜索框**   | 玻璃质感长椭圆矩形。内部右侧嵌套一个**圆形凸起 ⊕ 按钮**，点击弹出导入主要项 |
| 3    | **布局切换按钮** | 图标按钮，点击后在下方弹出 2×2 布局预设选择浮窗                             |
| 4    | **主题切换按钮** | 图标按钮，切换亮色 / 暗色主题                                               |
| 5    | **设置按钮**     | 齿轮图标按钮，点击弹出居中设置模态框                                        |
| 6    | **用户头像**     | 圆形头像占位（V1 暂不实现点击功能）                                         |
| 7    | **窗口控制键**   | Windows / Linux 风格的最小化、最大化（还原）、关闭按钮，位于最右侧          |

### 搜索框交互

- **默认状态**：显示占位提示文字（如"搜索 Meme…"）
- **聚焦状态**：搜索框向下拉伸展开，显示：
  - 最多 3 条搜索历史记录
  - "高级搜索"按钮（点击弹出高级搜索对话框）
- **提交方式**：实时无界过滤（Debounce 防抖搜索），无需按 `Enter` 键
- **⊕ 按钮交互**：点击后弹出下拉菜单，详见 [dialogs.md - 导入下拉菜单](dialogs.md#导入下拉菜单)

## 区域 2：左侧导航栏 (Sidebar)

> **宽度**：初始默认值，用户可通过右侧 Splitter 拖拽调整  
> **高度**：撑满顶栏与底栏之间的空间  
> **支持折叠**：可通过布局预设将侧边栏折叠为仅图标状态

### 三大分组

侧边栏内容分为三个可折叠分组，每个分组内的项目**支持拖拽排序**以自定义顺序：

#### 分组 1：系统级（固化区）

| 项目   | 图标    | 右侧计数 | 说明                           |
| ------ | ------- | -------- | ------------------------------ |
| 全部   | list    | 总数     | 显示所有梗图                   |
| 未标签 | tag-off | 计数     | 未打标签的梗图                 |
| 回收站 | trash   | 计数     | 已删除梗图，支持恢复与永久删除 |

#### 分组 2：快捷访问区

| 项目     | 图标  | 右侧计数 | 说明                                      |
| -------- | ----- | -------- | ----------------------------------------- |
| 最近使用 | clock | —        | 按时间排序，最近使用过（复制/导出）的梗图 |
| 经常使用 | star  | —        | 按使用频次排序的高频梗图                  |

#### 分组 3：归类区 (Categories)

| 项目     | 图标   | 右侧计数 | 说明                               |
| -------- | ------ | -------- | ---------------------------------- |
| 各个分类 | folder | 计数     | 用户手动创建的分类，支持多级(可选) |

#### 分组 4：魔法桶 (Magic Bucket) [NEW]

| 项目   | 图标   | 右侧计数 | 说明                                                                    |
| ------ | ------ | -------- | ----------------------------------------------------------------------- |
| 收集桶 | bucket | 暂存数   | **临时缓冲区**：支持跨分类选图；支持**一键转为静态合集 (Collection)**。 |


### 拖拽交互

- **排序拖拽**：在各分组内部可拖拽调整菜单项的上下排列顺序
- **归类拖拽**：从中间主区域将梗图拖放到左侧任意分类项上，实现快速归类
  - 拖拽时：梗图以**半透明缩略图**跟随鼠标
  - 悬停在有效目标时：该分类项**高亮发光**
  - 悬停在无效目标时（如"全部"）：不产生视觉提示

## 区域 3：中间主区域 (Gallery)

> **宽度**：自适应撑满左右 Splitter 之间的剩余空间  
> **高度**：撑满顶栏与底栏之间的区域  
> **渲染引擎**：`react-virtuoso` 虚拟列表，保证 DOM 节点数量恒定

### 顶部控制栏

位于主区域内部最上方的一排控制元素：

| 位置 | 元素            | 说明                                                           |
| ---- | --------------- | -------------------------------------------------------------- |
| 左侧 | ◀ 后退 / ▶ 前进 | 在不同筛选视图之间导航（如从"全部"进入某分类后可后退回去）     |
| 右侧 | 视图切换按钮    | 在网格 (Grid) 与瀑布流 (Masonry) 之间切换                      |
| 右侧 | 比例嵌合切换    | 切换梗图是否按原始比例嵌合排列（Contain）还是裁剪填满（Cover） |
| 右侧 | 标签显示切换    | 切换是否在每张梗图缩略图下方直接显示其主要标签                 |

### 梗图卡片 (MemeCard)

每张梗图在主区域内以卡片形式展示，详细组件规格见 [components.md - MemeCard](components.md#memecard-梗图卡片)。

**交互状态：**

| 状态 | 视觉表现                                                      |
| ---- | ------------------------------------------------------------- |
| 默认 | 纯图片展示，无附加元素                                        |
| 悬停 | 图片周围出现**高亮描边**；右下角浮现 **···（三点设置）** 按钮 |
| 选中 | 描边常驻高亮                                                  |
| 多选 | 每个被选中的卡片常驻高亮描边                                  |

**点击逻辑：**

| 操作         | 行为                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------ |
| 单击左键     | **立即复制该梗图到系统剪贴板**，右下角弹出 Toast："已复制到剪贴板"                         |
| 右键         | 打开上下文菜单（与三点按钮菜单一致），见 [interactions.md](interactions.md#右键上下文菜单) |
| Ctrl + 左键  | 追加选中 / 取消选中（多选模式）                                                            |
| Shift + 左键 | 范围选中（从上一个选中项到当前项之间的所有梗图）                                           |
| 鼠标框选     | 在空白区域按住拖动画出矩形，框内梗图全部选中（Rubber Band Selection）                      |

### 回收站视图

当用户在左侧栏选中"回收站"时，中间主区域切换为回收站特殊视图：

- 顶部显示淡色文字说明（如"已删除的梗图将在 30 天后自动永久删除"）
- 右上角排序选项新增：**按删除时间排序**、**按剩余生命周期排序**
- 鼠标悬停某梗图时，额外显示**剩余多久自动删除**的提示
- 提供"清空回收站"按钮

### 多选浮动操作条 (Float Action Bar) [NEW]

当用户在画廊中选中 **2 张或以上** 梗图时，在中间区域正下方（状态栏上方）浮现一个磨砂玻璃质感的浮动操作条。

*   **尺寸及定位**：高度约 56px，宽度依按钮数量自适应，水平居中。
*   **内容**：
    *   `[ N 张已选 ]`：左侧显示选中计数。
    *   操作按钮组：`[ 复制 ]` `[ 批量导出 ]` `[ 移动到... ]` `[ 丢进魔法桶 ]` `[ 删除 ]`。
    *   `[ ✕ ]`：最右侧取消选中按钮。
*   **出现方式**：通过 `slide-up-fade-in` 动效入场；取消全选时消失。
*   **设计初衷**：减少视线在画廊和右侧 Inspector 之间的长距离跳跃。

## 区域 4：右侧属性面板 (Inspector)

> **宽度**：初始默认值，用户可通过左侧 Splitter 拖拽调整  
> **高度**：撑满顶栏与底栏之间的空间  
> **激活条件**：默认隐藏，只有当用户通过上下文菜单或点击“编辑详情”按钮主动调整梗图属性时才从侧边滑出

### 单选模式

选中一张梗图时，面板从上到下依次展示 4 大内容块：

#### A. 基础信息（只读）

| 字段     | 说明                           |
| -------- | ------------------------------ |
| 文件名   | 原始文件名                     |
| 格式     | 图片格式（PNG / JPG / GIF 等） |
| 文件大小 | 如 "2.78 MB"                   |
| 分辨率   | 如 "1500×2250"                 |
| 添加时间 | 导入到图库的时间               |
| 修改时间 | 最后修改属性的时间             |

#### B. 标签管理

- 显示当前梗图已有的标签列表（胶囊 Chip 样式，每个带 × 删除按钮）
- 底部提供标签输入框，支持快速添加新标签
- 输入时提供已有标签的自动补全建议

#### C. OCR 识别文本

- 展示从该梗图中提取的文字内容
- 提供"一键复制"按钮
- 文本区域可编辑，允许用户修正 OCR 识别错误后保存

#### D. 来源信息

- 展示梗图的收集来源（URL 或平台名称）
- 提供可编辑输入框，允许用户新增或修改来源链接
- URL 格式的来源支持点击跳转

### 多选模式

选中多张梗图时，面板切换为批量操作视图：

| 元素         | 说明                             |
| ------------ | -------------------------------- |
| 选中数量提示 | 显示"已选中 N 张图片"            |
| 批量添加标签 | 输入标签后同时为所有选中梗图添加 |
| 批量删除     | 将所有选中梗图移到回收站         |
| 批量导出     | 批量导出选中梗图                 |

## 区域 5：底部状态栏 (StatusBar)

> **高度**：固定（极窄条状）  
> **宽度**：撑满窗口  
> **视觉风格**：类似 VSCode 底栏的沉稳配色

### 元素排列

| 位置 | 元素       | 说明                                                                    |
| ---- | ---------- | ----------------------------------------------------------------------- |
| 左侧 | 图库统计   | 当前图库总梗图数量、当前选中数量                                        |
| 中间 | 任务进度   | 后台任务进行中时显示进度条和描述（如"OCR 处理中 45/200"）；无任务时隐藏 |
| 右侧 | 通知指示灯 | 圆形小点，默认绿色；根据未读通知最高等级变色（黄色=警告，红色=错误）    |

### 通知指示灯交互

- **默认**：绿色圆点，表示无未读通知
- **收到通知时**：
  - 右下角弹出气泡悬浮窗口预览通知内容
  - 若用户未处理，指示灯变色为通知的严重等级色
- **点击指示灯**：向上展开通知面板，详见 [dialogs.md - 通知面板](dialogs.md#通知面板)

## 可拖拽分割线 (Splitter)

应用中有 **2 条**垂直方向的可拖拽分割线：

| 分割线        | 位置                  | 控制目标     |
| ------------- | --------------------- | ------------ |
| 左侧 Splitter | 左侧栏 ↔ 中间主区域   | 左侧栏宽度   |
| 右侧 Splitter | 中间主区域 ↔ 右侧面板 | 右侧面板宽度 |

### 行为规格

- 鼠标悬停时光标变为 `col-resize`（左右箭头）
- 拖拽时实时更新两侧区域宽度
- 宽度值通过 Zustand 状态管理持久化，下次启动时恢复
- 设有最小宽度限制，防止区域被完全压缩

## 布局预设

通过顶部操作栏的"布局切换按钮"弹出 2×2 选择面板，提供 4 种布局预设：

```
┌─────────────────────┬─────────────────────┐
│                     │                     │
│  [左栏展开] + 中间  │  [左栏展开] + 中间  │
│     + [右栏展开]    │     + [右栏隐藏]    │
│                     │                     │
├─────────────────────┼─────────────────────┤
│                     │                     │
│  [左栏折叠] + 中间  │  [左栏折叠] + 中间  │
│     + [右栏展开]    │     + [右栏隐藏]    │
│                     │                     │
└─────────────────────┴─────────────────────┘
```

| 预设 | 左侧栏 | 右侧面板 | 适用场景             |
| ---- | ------ | -------- | -------------------- |
| 1    | 展开   | 展开     | 完整管理模式         |
| 2    | 展开   | 隐藏     | 效率优先模式（默认） |
| 3    | 折叠   | 展开     | 快速查看属性细节     |
| 4    | 折叠   | 隐藏     | 极简全屏浏览模式     |

- **展开**：显示完整内容
- **折叠**：侧边栏仅保留图标，隐藏文字标签
- **隐藏**：面板完全不可见，中间区域铺满
