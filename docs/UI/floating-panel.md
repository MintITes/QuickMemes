# 便捷悬浮选择窗口 (Convenience Floating Panel)

> **所属层级**：前端 UI 设计 — 悬浮面板  
> **索引**：[UI.md](UI.md) · [布局规格](layout.md)  
> **技术接口**：[frontend.md - showMemePanel()](../arch/frontend.md#showmemepanel) / [hideMemePanel()](../arch/frontend.md#hidememepanel)

---

## 功能定位

便捷悬浮选择窗口是一个**全局快捷键驱动、光标跟随的轻量化取图工具**。它旨在让用户在聊天或写作时，无需切换窗口即可快速“盲打”或点击选取梗图，并利用**自动粘贴**功能直接发送。

---

## 视觉规格

| 属性         | 规格                         | 说明                                     |
| ------------ | ---------------------------- | ---------------------------------------- |
| **窗口尺寸** | 400px × 500px                | 极致紧凑，类输入法皮肤尺寸               |
| **定位策略** | 光标跟随 (Caret Following)   | 紧贴输入光标弹出；底部空间不足则上弹     |
| **背景风格** | 强力磨砂玻璃 (Vibrant Glass) | 较高的模糊度 (blur: 20px)                |
| **圆角半径** | 16px                         | 紧致圆角                                 |
| **窗口属性** | 置顶 (Topmost) + 透明        | `alwaysOnTop: true`, `transparent: true` |

---

## 布局结构

### 1. 顶部：搜索区 (Compact Search)
- **极简搜索框**：仅包含搜索图标和占位文字。
- **无页签设计**：页签已移动至底部，保持顶部视觉清爽。

### 2. 中间：滚动列表 (Quick Gallery)
- **4 行 5 列网格**：每屏固定展示 20 个预览位。
- **默认排序**：无搜索时，默认按“最近使用”排序。
- **缩略图规格**：约 100px × 100px。原始比例非 1:1 时，**保持比例压缩至长边等于 100px**。
- **悬停放大**：鼠标悬停在表情上（或键盘选中时），在侧边弹出**放大预览图**（Magnified View），方便识别文字和 GIF 动效。

### 3. 底部：动态状态栏 (Dynamic Footer)
- **闲置态 (无搜索内容)**：显示页签切换：`[ 常用 ] [ 收藏 ]`（支持 `Tab` 键或点击切换）。
- **搜索态 (输入中)**：显示 `找到 N 个结果`。

---

## 交互流程

### 唤起与关闭
- **快捷键开启**：`Alt+M` 唤出。
- **智能焦点**：开启时不自动聚焦。用户开始按键时，焦点瞬时跳入搜索框并接收输入。
- **自动消失与粘贴**：
    - **确认选择**：用户点击图片或按 `Enter/Ctrl+C/c` 后，程序自动执行：`写入剪贴板` -> `发送 Ctrl+V (Cmd+V) 信号` -> `立即关闭窗口`。
    - **主动退出**：按下 `Esc` 或点击窗口外区域时直接关闭。

### 浏览与选择
- **全键盘支持**：方向键导航。
- **预览增强**：不仅鼠标悬停，键盘焦点移动也会触发侧边放大预览。
