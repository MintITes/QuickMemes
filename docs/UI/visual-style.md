## 设计语言

QuickMemes 的视觉设计基于以下核心理念：

| 维度 | 选择                     | 说明                                       |
| ---- | ------------------------ | ------------------------------------------ |
| 风格 | 磨砂玻璃 (Glassmorphism) | 半透明背景 + 模糊效果，类似 macOS          |
| 圆角 | 大圆角                   | 柔和、现代的视觉感受                       |
| 密度 | 适中                     | 既不过于松散也不过于紧凑；支持动态感应调整 |
| 色彩 | 柔和、高级               | 避免纯色高饱和，偏向低饱和、高明度的配色   |

## 网格动态适配 [NEW]

为了平衡视觉呼吸感与信息密度，网格布局支持动态关联调整：
*   **缩放联动**：当用户调大图片尺寸时，网格间距（Gap）按比例自动缩减；当图片尺寸调小时，间距适度增大。
*   **视觉重心**：保证无论缩放比例如何，画廊始终呈现出平衡的视觉节奏。

## 主题系统

### 主题模式

| 模式         | 说明                               |
| ------------ | ---------------------------------- |
| 跟随系统     | **默认选项**。读取操作系统主题偏好 |
| 亮色 (Light) | 浅色背景主题                       |
| 暗色 (Dark)  | 深色背景主题                       |

> **设计初衷**：默认跟随系统，确保暗色模式用户首次打开应用时不会被亮色界面闪到。

### 亮色主题色彩参考

| 用途        | 色彩描述                               |
| ----------- | -------------------------------------- |
| 背景 (主)   | 浅灰白色                               |
| 背景 (副)   | 更浅的灰白色（面板、侧边栏）           |
| 前景 (文字) | 深灰色至近黑色                         |
| 强调色      | 柔和蓝紫色系（用于选中态、按钮高亮等） |
| 边框        | 极淡灰色                               |
| 阴影        | 柔和的灰色投影                         |

### 暗色主题色彩参考

| 用途        | 色彩描述                         |
| ----------- | -------------------------------- |
| 背景 (主)   | 深灰色（非纯黑，如 #1a1a2e）     |
| 背景 (副)   | 略浅的深灰色                     |
| 前景 (文字) | 浅灰色至近白色                   |
| 强调色      | 与亮色主题相同色相，亮度适当提升 |
| 边框        | 极细 `rgba(255, 255, 255, 0.05)` |
| 阴影        | 更深的黑色投影                   |

### CSS 实现建议

通过 CSS 自定义属性（CSS Variables）实现主题切换：

```css

    --bg-primary: /* 由主题决定 */;
    --bg-secondary: /* 由主题决定 */;
    --text-primary: /* 由主题决定 */;
    --accent-color: /* 由主题决定 */;
    --border-color: /* 由主题决定 */;
    --glass-bg: /* 由主题决定 */;
    --glass-blur: /* 由主题决定 */;
}
```

## 磨砂玻璃效果

QuickMemes 的核心视觉特征，应用于以下组件：

| 组件               | 效果程度 | 说明                                                      |
| ------------------ | -------- | --------------------------------------------------------- |
| GlassSearchBar     | 强       | 顶栏核心组件，高度模糊 + 半透明背景                       |
| 各类弹窗/菜单背景  | 中       | 下拉菜单、上下文菜单、通知面板                            |
| Toast 通知         | 中       | 浮动在内容上方，需要清晰的区隔                            |
| 主画廊/侧边栏/面板 | 无       | （出于性能考量，展示大量图片的区域使用纯色/跟随系统底色） |

### 原生穿透效果适配
- **支持平台**：macOS (Vibrant) / Windows 10+ (Acrylic)。
- **配置逻辑**：**设置中默认开启**，允许用户手动关闭以退回到纯 CSS `backdrop-filter` 模拟。
- **噪点层 (Noise Overlay)**：在磨砂玻璃背景上叠加 **1%-2% 不透明度**的超细微颗粒噪点，提升设计的厚重感与真实感。

```css
.glass-effect {
    background: var(--glass-bg);               /* rgba(255, 255, 255, 0.7) */
    backdrop-filter: blur(var(--glass-blur));  /* 12px - 20px */
    border: 1px solid var(--border-color);
    position: relative;
    overflow: hidden;
}

/* 噪点层示例 */
.glass-effect::before {
    content: "";
    position: absolute;
    inset: 0;
    background-image: url('noise.png'); /* 或高度缩小的随机图案 */
    opacity: 0.02;
    pointer-events: none;
}
```

## 空间层级与 Z-index (Spatial Hierarchy) [NEW]

通过明确的 Z 轴堆叠语义，营造真实的空间纵深感：

| 层级        | Z-index 参考 | 适用组件                      | 说明                                  |
| :---------- | :----------- | :---------------------------- | :------------------------------------ |
| **Level 0** | `0`          | 底层背景                      | 桌面穿透 (Acrylic/Vibrant) 效果层     |
| **Level 1** | `100`        | 主网格画廊                    | 保持纯色/弱透明，确保海量图片滚动性能 |
| **Level 2** | `200`        | 侧边栏、工具栏、分割线        | 核心功能框架层                        |
| **Level 3** | `400`        | FAB、Toast、浮动菜单          | 悬浮于内容之上的即时反馈层            |
| **Level 4** | `600`        | 模态框、灯箱遮罩              | 全局独占性操作层，配合 Adaptive Tint  |
| **Level 5** | `1000+`      | 快捷键速查层 (Keymap Overlay) | 最高优先级视图层                      |

| :----------- | :--------------- | :---------------------------- |

## 动效与过渡

### 通用原则

| 原则     | 说明                                                   |
| :------- | :----------------------------------------------------- |
| 自然流畅 | 所有过渡使用 ease-out 或 cubic-bezier 缓动             |
| 快速响应 | 交互反馈不超过 200ms                                   |
| 不干扰   | 动效为辅助，不应延迟用户操作                           |
| 弹性入场 | 悬浮类组件（如 FAB）建议使用微小的弹性效果 (Overshoot) |
| 可关闭   | 尊重系统 `prefers-reduced-motion` 偏好                 |

### 具体动效列表

| 动效场景           | 描述                                   | 时长参考     |
| :----------------- | :------------------------------------- | :----------- |
| 按钮悬停           | 背景淡入                               | ~150ms       |
| 按钮按下           | 轻微缩放 (scale 0.95)                  | ~100ms       |
| **卡片点击瞬间**   | **下沉感 (scale 0.99) + 高亮闪烁**     | **~150ms**   |
| 菜单弹出           | 从触发点向外淡入+微缩放                | ~200ms       |
| 菜单关闭           | 淡出                                   | ~150ms       |
| Toast 出现         | 从右侧滑入+淡入                        | ~300ms       |
| Toast 消失         | 淡出+向右滑出                          | ~300ms       |
| 模态框打开         | 居中淡入+缩放 (0.95 → 1.0)             | ~250ms       |
| 模态框关闭         | 淡出+缩放 (1.0 → 0.95)                 | ~200ms       |
| FAB 弹出           | **弹性 slide-up + 淡入**               | **~400ms**   |
| 侧边栏折叠/展开    | 宽度过渡                               | ~300ms       |
| 搜索框展开历史记录 | 高度向下拉伸                           | ~250ms       |
| 灯箱打开           | 背景遮罩淡入 + 图片缩放入场            | ~300ms       |
| 灯箱关闭           | 反向缩放 + 遮罩淡出                    | ~250ms       |
| 通知面板展开       | 从底部向上滑出                         | ~250ms       |
| 通知滑动填补       | 通知项向下平滑滑动                     | ~300ms       |
| 通知指示灯呼吸     | 未读时缓慢透明度循环                   | ~2000ms 循环 |
| MemeCard 悬停描边  | 边框颜色淡入                           | ~150ms       |
| MoreButton 出现    | 从右下角淡入                           | ~150ms       |
| 拖拽开始           | 原位卡片透明度降低                     | ~150ms       |
| 拖拽目标高亮       | 边框发光淡入                           | ~200ms       |
| **磁性吸附响应**   | **Sidebar 图标轻微向鼠标偏移 + 缩放**  | **~200ms**   |
| 进度条填充         | 宽度平滑过渡                           | 连续         |
| 进度条完成消失     | 淡出                                   | ~500ms       |
| **进度条完成**     | **光效扫过 (Shine Overflow)**          | **~500ms**   |
| **批量导出完成**   | **缩略图向目标方向产生的粒子飞散动画** | **~600ms**   |
| **全局引导层**     | **淡入 + 高斯模糊**                    | **~300ms**   |

## 骨架屏设计规范 [NEW]

在图片未完全加载或长列表快速滚动时，使用骨架屏（Skeleton Screen）缓解用户焦虑并保持画面的灵动感。

*   **色块策略**：不使用单一灰色，而是从主题调色盘中预置 4-5 种高明度、极低饱和度的莫兰迪淡色，随机分配给占位卡片。
*   **微动效**：每个色块叠加一个从左至右的半透明扫光（Shimmer）动画。
*   **平滑交替**：图片加载完毕后，通过 200ms 的淡入动画覆盖骨架屏。

## 智能取色策略 (Adaptive Lightbox) [NEW]

在灯箱预览（Lightbox）等沉浸式场景中，背景遮罩不仅仅使用纯黑半透明，而是基于算法自动调整。

*   **取色逻辑**：实时计算当前展示梗图的主色调。
*   **应用方式**：将该色相应用于背景悬浮层，设定极高的透明度（如 `rgba(main_color, 0.15)`）或极弱的色彩叠加（Tint），使背景与图片内容在视觉上更加和谐融合。

## 空状态设计

当特定视图无内容时，主区域居中展示空状态组件：

### 设计模板

```
         ┌─────────────────────────┐
         │                         │
         │       🖼️ 插图           │
         │   (简约矢量风格图形)    │
         │                         │
         │   引导文案              │
         │   （简短易懂的一句话）   │
         │                         │
         │   [ 操作按钮 ] (可选)   │
         │                         │
         └─────────────────────────┘
```

### 各场景内容

| 场景       | 插图主题    | 引导文案                       | 操作按钮   |
| ---------- | ----------- | ------------------------------ | ---------- |
| 图库空     | 空画框/相册 | "还没有梗图，导入你的第一张！" | "导入梗图" |
| 搜索无结果 | 放大镜/问号 | "没有找到匹配的梗图"           | "清除搜索" |
| 回收站空   | 空垃圾桶    | "回收站是空的"                 | —          |
| 未标签为空 | 勋章/标签   | "所有梗图都已打上标签 🎉"       | —          |
| 分类为空   | 空文件夹    | "这个分类还没有梗图"           | "导入梗图" |

## 拖拽视觉反馈

### 从主区域拖拽梗图到左侧分类

| 开始拖拽     | 原位 MemeCard 变为 **30% 透明度**；鼠标旁出现半透明缩略图副本（多选时显示层叠卡片） |
| 悬停有效目标 | 左侧 SidebarItem 出现**发光边框**并触发**磁性吸附 (Magnetic)** 图标缩放动画         |
| 悬停无效目标 | 无特殊视觉变化                                                                     |
| 释放到目标   | 高亮消失，弹出成功 Toast                                                           |
| 释放到空白   | 取消拖拽，所有视觉效果恢复                                                         |

### 全局文件拖入

| 阶段             | 视觉效果                             |
| ---------------- | ------------------------------------ |
| 系统文件进入窗口 | 快捷导入窗口自动弹出，放置区边框高亮 |
| 悬停放置区       | 放置区背景变亮，图标放大             |
| 离开窗口         | 导入窗口自动关闭                     |
| 释放文件         | 开始导入流程                         |

## 滚动条样式

为保持整体视觉一致性，采用自定义滚动条：

| 属性     | 规格                                 |
| -------- | ------------------------------------ |
| 宽度     | 较细（~6px）                         |
| 轨道     | 透明或极淡背景                       |
| 滑块     | 圆角胶囊形，半透明灰色               |
| 悬停滑块 | 透明度提高，颜色加深                 |
| 拖拽中   | 与悬停态一致                         |
| 隐藏行为 | 不滚动时自动隐藏（淡出），滚动时淡入 |
