## 设计语言

QuickMemes 的视觉设计基于以下核心理念：

| 维度 | 选择                     | 说明                                           |
| ---- | ------------------------ | ---------------------------------------------- |
| 风格 | 磨砂玻璃 (Glassmorphism) | 半透明背景 + 模糊效果，类似 macOS              |
| 圆角 | 大圆角                   | 柔和、现代的视觉感受                           |
| 密度 | 适中                     | 既不过于松散（浪费空间）也不过于紧凑（压迫感） |
| 色彩 | 柔和、高级               | 避免纯色高饱和，偏向低饱和、高明度的配色       |

## 主题系统

### 主题模式

| 模式         | 说明                               |
| ------------ | ---------------------------------- |
| 跟随系统     | **默认选项**。读取操作系统主题偏好 |
| 亮色 (Light) | 浅色背景主题                       |
| 暗色 (Dark)  | 深色背景主题                       |

> **设计初衷**：默认跟随系统，确保暗色模式用户首次打开应用时不会被亮色界面闪到。

### 亮色主题色彩参考

| 用途        | 色彩描述                               |
| ----------- | -------------------------------------- |
| 背景 (主)   | 浅灰白色                               |
| 背景 (副)   | 更浅的灰白色（面板、侧边栏）           |
| 前景 (文字) | 深灰色至近黑色                         |
| 强调色      | 柔和蓝紫色系（用于选中态、按钮高亮等） |
| 边框        | 极淡灰色                               |
| 阴影        | 柔和的灰色投影                         |

### 暗色主题色彩参考

| 用途        | 色彩描述                         |
| ----------- | -------------------------------- |
| 背景 (主)   | 深灰色（非纯黑，如 #1a1a2e）     |
| 背景 (副)   | 略浅的深灰色                     |
| 前景 (文字) | 浅灰色至近白色                   |
| 强调色      | 与亮色主题相同色相，亮度适当提升 |
| 边框        | 深灰色                           |
| 阴影        | 更深的黑色投影                   |

### CSS 实现建议

通过 CSS 自定义属性（CSS Variables）实现主题切换：

```css
:root {
    --bg-primary: /* 由主题决定 */;
    --bg-secondary: /* 由主题决定 */;
    --text-primary: /* 由主题决定 */;
    --accent-color: /* 由主题决定 */;
    --border-color: /* 由主题决定 */;
    --glass-bg: /* 由主题决定 */;
    --glass-blur: /* 由主题决定 */;
}
```

## 圆角规范

按组件层级分为三档：

| 档位   | 圆角半径参考 | 适用组件                                      |
| ------ | ------------ | --------------------------------------------- |
| 小圆角 | ~6–8px       | 卡片 (MemeCard)、TagChip 胶囊、进度条、小按钮 |
| 中圆角 | ~12–16px     | 输入框、下拉菜单、对话框                      |
| 大圆角 | ~16–24px     | 搜索框 (GlassSearchBar)、Toast、模态框外框    |

## 磨砂玻璃效果

QuickMemes 的核心视觉特征，应用于以下组件：

| 组件               | 效果程度 | 说明                                                      |
| ------------------ | -------- | --------------------------------------------------------- |
| GlassSearchBar     | 强       | 顶栏核心组件，高度模糊 + 半透明背景                       |
| 各类弹窗/菜单背景  | 中       | 下拉菜单、上下文菜单、通知面板                            |
| Toast 通知         | 中       | 浮动在内容上方，需要清晰的区隔                            |
| 主画廊/侧边栏/面板 | 无       | （出于性能考量，展示大量图片的区域使用纯色/跟随系统底色） |

### CSS 实现参考

```css
.glass-effect {
    background: var(--glass-bg);     /* 如 rgba(255, 255, 255, 0.7) */
    backdrop-filter: blur(var(--glass-blur));  /* 如 blur(12px) */
    border: 1px solid var(--border-color);
}
```

## 阴影规范

| 层级     | 使用场景               | 阴影描述                   |
| -------- | ---------------------- | -------------------------- |
| 无阴影   | 嵌入式组件（输入框等） | —                          |
| 柔和阴影 | 卡片、面板             | 模糊的淡灰色投影           |
| 中等阴影 | 弹出菜单、下拉框       | 比柔和阴影更明显的灰色投影 |
| 强阴影   | 模态框、灯箱           | 最强的分层阴影             |

## 动效与过渡

### 通用原则

| 原则     | 说明                                       |
| -------- | ------------------------------------------ |
| 自然流畅 | 所有过渡使用 ease-out 或 cubic-bezier 缓动 |
| 快速响应 | 交互反馈不超过 200ms                       |
| 不干扰   | 动效为辅助，不应延迟用户操作               |
| 可关闭   | 尊重系统 `prefers-reduced-motion` 偏好     |

### 具体动效列表

| 动效场景           | 描述                        | 时长参考     |
| ------------------ | --------------------------- | ------------ |
| 按钮悬停           | 背景淡入                    | ~150ms       |
| 按钮按下           | 轻微缩放 (scale 0.95)       | ~100ms       |
| 菜单弹出           | 从触发点向外淡入+微缩放     | ~200ms       |
| 菜单关闭           | 淡出                        | ~150ms       |
| Toast 出现         | 从右侧滑入+淡入             | ~300ms       |
| Toast 消失         | 淡出+向右滑出               | ~300ms       |
| 模态框打开         | 居中淡入+缩放 (0.95 → 1.0)  | ~250ms       |
| 模态框关闭         | 淡出+缩放 (1.0 → 0.95)      | ~200ms       |
| 侧边栏折叠/展开    | 宽度过渡                    | ~300ms       |
| 搜索框展开历史记录 | 高度向下拉伸                | ~250ms       |
| 灯箱打开           | 背景遮罩淡入 + 图片缩放入场 | ~300ms       |
| 灯箱关闭           | 反向缩放 + 遮罩淡出         | ~250ms       |
| 通知面板展开       | 从底部向上滑出              | ~250ms       |
| 通知滑动填补       | 通知项向下平滑滑动          | ~300ms       |
| 通知指示灯呼吸     | 未读时缓慢透明度循环        | ~2000ms 循环 |
| MemeCard 悬停描边  | 边框颜色淡入                | ~150ms       |
| MoreButton 出现    | 从右下角淡入                | ~150ms       |
| 拖拽开始           | 原位卡片透明度降低          | ~150ms       |
| 拖拽目标高亮       | 边框发光淡入                | ~200ms       |
| 进度条填充         | 宽度平滑过渡                | 连续         |
| 进度条完成消失     | 淡出                        | ~500ms       |

## 空状态设计

当特定视图无内容时，主区域居中展示空状态组件：

### 设计模板

```
         ┌─────────────────────────┐
         │                         │
         │       🖼️ 插图           │
         │   (简约矢量风格图形)    │
         │                         │
         │   引导文案              │
         │   （简短易懂的一句话）   │
         │                         │
         │   [ 操作按钮 ] (可选)   │
         │                         │
         └─────────────────────────┘
```

### 各场景内容

| 场景       | 插图主题    | 引导文案                       | 操作按钮   |
| ---------- | ----------- | ------------------------------ | ---------- |
| 图库空     | 空画框/相册 | "还没有梗图，导入你的第一张！" | "导入梗图" |
| 搜索无结果 | 放大镜/问号 | "没有找到匹配的梗图"           | "清除搜索" |
| 回收站空   | 空垃圾桶    | "回收站是空的"                 | —          |
| 未标签为空 | 勋章/标签   | "所有梗图都已打上标签 🎉"       | —          |
| 分类为空   | 空文件夹    | "这个分类还没有梗图"           | "导入梗图" |

## 拖拽视觉反馈

### 从主区域拖拽梗图到左侧分类

| 阶段         | 视觉效果                                                      |
| ------------ | ------------------------------------------------------------- |
| 开始拖拽     | 原位 MemeCard 变为 **30% 透明度**；鼠标旁出现半透明缩略图副本 |
| 悬停有效目标 | 左侧 SidebarItem 出现**发光边框**（强调色 glow 效果）         |
| 悬停无效目标 | 无特殊视觉变化                                                |
| 释放到目标   | 高亮消失，弹出成功 Toast                                      |
| 释放到空白   | 取消拖拽，所有视觉效果恢复                                    |

### 全局文件拖入

| 阶段             | 视觉效果                             |
| ---------------- | ------------------------------------ |
| 系统文件进入窗口 | 快捷导入窗口自动弹出，放置区边框高亮 |
| 悬停放置区       | 放置区背景变亮，图标放大             |
| 离开窗口         | 导入窗口自动关闭                     |
| 释放文件         | 开始导入流程                         |

## 滚动条样式

为保持整体视觉一致性，采用自定义滚动条：

| 属性     | 规格                                 |
| -------- | ------------------------------------ |
| 宽度     | 较细（~6px）                         |
| 轨道     | 透明或极淡背景                       |
| 滑块     | 圆角胶囊形，半透明灰色               |
| 悬停滑块 | 透明度提高，颜色加深                 |
| 拖拽中   | 与悬停态一致                         |
| 隐藏行为 | 不滚动时自动隐藏（淡出），滚动时淡入 |
