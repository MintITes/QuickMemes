## 按钮类组件

### IconButton 图标按钮

通用图标按钮，用于顶栏工具按钮组（布局切换、主题切换、设置等）。

| 属性 | 规格                       |
| ---- | -------------------------- |
| 形状 | 正方形，大圆角             |
| 尺寸 | 与顶栏高度协调的固定尺寸   |
| 内容 | 居中图标（SVG / 图标字体） |

| 状态 | 视觉表现                                   |
| ---- | ------------------------------------------ |
| 默认 | 图标色与背景色有适当对比度                 |
| 悬停 | 背景出现磨砂半透明填充，图标微亮           |
| 按下 | 背景进一步加深，轻微缩放动画（scale 0.95） |
| 禁用 | 灰度化，降低透明度，不响应交互             |

---

### PlusButton 圆形加号按钮

嵌套在搜索框右侧内部的导入快捷按钮。

| 属性 | 规格                                           |
| ---- | ---------------------------------------------- |
| 形状 | 正圆形，**凸起**于搜索框表面（有微妙的层级感） |
| 尺寸 | 直径略小于搜索框高度                           |
| 内容 | 居中 "+" 图标                                  |
| 位置 | 搜索框内部右侧，紧贴搜索框右边缘               |

| 状态 | 视觉表现                           |
| ---- | ---------------------------------- |
| 默认 | 主题强调色背景 + 白色"+"图标       |
| 悬停 | 背景色加亮，轻微放大（scale 1.05） |
| 按下 | 背景色加深，恢复原始大小           |
| 激活 | 下拉菜单已展开时，按钮保持按下态   |

---

### WindowControlButton 窗口控制键

根据所运行的操作系统动态显示原生风格的窗口控制按钮。

| 属性 | 规格                                                    |
| ---- | ------------------------------------------------------- |
| 形状 | (macOS) 三个正圆形紧密排列 / (Win/Linux) 矩形块状图标   |
| 颜色 | (macOS) 红、黄、绿 / (Win/Linux) 纯色图标或随系统强调色 |
| 布局 | 水平排列，位于顶栏最左侧(macOS) 或最右侧(Win/Linux)     |

| 状态     | macOS 视觉表现                      | Win/Linux 视觉表现                |
| -------- | ----------------------------------- | --------------------------------- |
| 默认     | 圆点填充对应颜色                    | 标准系统图标 (×、−、☐)            |
| 悬停     | 对应的图标在圆点中心浮现（×、−、⤢） | 背景高亮 (关闭按钮通常为红色背景) |
| 按下     | 颜色加深                            | 背景加深                          |
| 窗口失焦 | 三个圆点统一变为灰色                | 图标透明度降低                    |

---

### NavButton 导航按钮

主区域顶部的后退 / 前进导航按钮。

| 属性 | 规格             |
| ---- | ---------------- |
| 形状 | 圆形或圆角正方形 |
| 内容 | ◀ 或 ▶ 箭头图标  |

| 状态 | 视觉表现                                   |
| ---- | ------------------------------------------ |
| 默认 | 正常图标色                                 |
| 悬停 | 背景半透明填充                             |
| 禁用 | 灰度化（如：已经是第一个视图，后退不可用） |

---

### ToggleButton 切换按钮

用于视图切换（Grid/Masonry）、比例嵌合切换、标签显示切换等。

| 属性 | 规格                      |
| ---- | ------------------------- |
| 形状 | 圆角矩形                  |
| 类型 | 二元切换（选中 / 未选中） |
---

### `SidebarCategoryItem` — 侧边栏分类项

*   **视觉**：
    *   图标（Folder）+ 名称 + 计数气泡。
    *   背景颜色可通过 `color` 属性自定义（小色块提示）。
*   **交互**：
    *   单击：切换主区域筛选条件（`searchQuery.categoryId = id`）。
    *   右键：弹出“重命名”、“修改颜色”、“删除分类”菜单。
    *   作为 Drop 目标：接收拖拽的 Meme。

| 状态   | 视觉表现                       |
| ------ | ------------------------------ |
| 未选中 | 无背景填充，仅图标             |
| 选中   | 背景半透明强调色填充，图标高亮 |
| 悬停   | 轻微背景填充                   |

## 输入类组件

### GlassSearchBar 玻璃搜索框

顶栏核心搜索组件，承载搜索与导入两大入口。

| 属性 | 规格                                                |
| ---- | --------------------------------------------------- |
| 形状 | 长椭圆矩形（大圆角），磨砂玻璃质感背景              |
| 宽度 | 居中自适应，占据顶栏中间的大部分空间                |
| 内部 | 左侧搜索图标 🔍 + 文本输入区域 + 右侧嵌入 PlusButton |

| 状态   | 视觉表现                            |
| ------ | ----------------------------------- |
| 默认   | 磨砂背景 + 占位文字（"搜索 Meme…"） |
| 聚焦   | 边框发光，向下拉伸展开历史记录区域  |
| 有输入 | 占位文字消失，高亮光标闪烁          |

### 聚焦展开区域

| 元素         | 说明                                        |
| ------------ | ------------------------------------------- |
| 历史记录列表 | 最多显示 3 条最近搜索记录，支持点击快速填入 |
| 高级搜索按钮 | 文本链接样式，点击弹出高级搜索对话框        |

---

### TagInput 标签输入框

右侧属性面板中用于管理标签的输入组件。

| 属性 | 规格                                       |
| ---- | ------------------------------------------ |
| 形状 | 圆角矩形输入框                             |
| 行为 | 输入时显示自动补全下拉列表，回车创建新标签 |

| 状态   | 视觉表现                  |
| ------ | ------------------------- |
| 默认   | 带占位文字（"添加标签…"） |
| 聚焦   | 边框高亮                  |
| 输入中 | 下方出现自动补全候选列表  |

---

### OcrTextArea OCR 文本编辑区

右侧属性面板中展示和修正 OCR 识别结果的文本区域。

| 属性 | 规格                                 |
| ---- | ------------------------------------ |
| 形状 | 圆角矩形多行文本框                   |
| 功能 | 只读展示 → 点击进入编辑 → 修改后保存 |

| 状态   | 视觉表现                                   |
| ------ | ------------------------------------------ |
| 只读   | 文字展示，右上角显示"复制"按钮             |
| 编辑中 | 边框高亮，文本可编辑，右上角变为"保存"按钮 |
| 空状态 | 淡色提示"暂无 OCR 识别结果"                |

## 展示类组件

### MemeCard 梗图卡片

主区域中画廊流里每张梗图的展示单位。

| 属性     | 规格                                         |
| -------- | -------------------------------------------- |
| 形状     | 圆角矩形卡片                                 |
| 内容     | 图片缩略图（按视图模式决定是否裁剪）         |
| 附属     | 可选的底部标签区域（标签显示模式开启时出现） |
| 悬浮元素 | 悬停时右下角浮现 MoreButton 与 QuickCopyIcon |

| 状态   | 视觉表现                                                                               |
| ------ | -------------------------------------------------------------------------------------- |
| 默认   | 纯图片，无边框或阴影                                                                   |
| 悬停   | 图片周围出现**高亮描边**；右下角浮现 **···（三点设置）** 按钮及 **📋（快捷复制）** 图标 |
| 单击   | **产生下沉感 (scale 0.99)** 并选中卡片                                                 |
| 双击   | 触发高亮闪烁，随后执行复制动作                                                         |
| 选中   | 描边常驻高亮                                                                           |
| 多选中 | 与选中一致的描边效果                                                                   |
| 拖拽中 | 原位卡片半透明化，鼠标旁显示半透明缩略图副本                                           |

---

### SkeletonCard 骨架屏卡片 [NEW]

在图片加载中或快速滚动到虚拟列表空白处时显示的占位组件。

| 属性 | 规格                                                    |
| ---- | ------------------------------------------------------- |
| 样式 | 与 MemeCard 尺寸一致的圆角矩形                          |
| 背景 | 动态随机取色（取自主题调色盘的 4-5 种极淡的莫兰迪色系） |
| 动效 | 扫光（Shimmer）效果，透明度在 0.4 到 0.6 之间循环       |

| 交互行为     | 说明                                                     |
| ------------ | -------------------------------------------------------- |
| 图片加载完成 | 通过淡入效果平滑替换骨架屏                               |
| 快速滚动     | 优先显示随机色块，保证滚动视觉灵动感，而非单调的灰色占位 |

## 容器类组件

### Splitter 可拖拽分割线

两个相邻区域之间的宽度调整控件。

| 属性 | 规格                                       |
| ---- | ------------------------------------------ |
| 方向 | 垂直（控制左右宽度）                       |
| 宽度 | 视觉上极细（~4px），但拖拽热区更宽（~8px） |
| 数量 | 2 条（左栏 ↔ 主区域、主区域 ↔ 右侧面板）   |

| 状态   | 视觉表现                              |
| ------ | ------------------------------------- |
| 默认   | 几乎不可见的细线                      |
| 悬停   | 线条变亮或变粗，光标变为 `col-resize` |
| 拖拽中 | 线条高亮，两侧区域实时调整宽度        |

---

### CollapsibleGroup 折叠分组

左侧导航栏中的三大分组容器。

| 属性 | 规格                    |
| ---- | ----------------------- |
| 结构 | 分组标题 + 可折叠内容区 |
| 交互 | 点击标题折叠/展开       |

| 状态     | 视觉表现                                         |
| -------- | ------------------------------------------------ |
| 展开     | 标题旁箭头向下 ▼，内容区可见                     |
| 折叠     | 标题旁箭头向右 ▶，内容区隐藏                     |
| 拖拽排序 | 内部项目可拖拽调整顺序，拖拽时显示插入位置指示线 |

---

### SidebarItem 侧边栏菜单项

折叠分组内的每个可点击菜单条目。

| 属性 | 规格                           |
| ---- | ------------------------------ |
| 内容 | 图标 + 文字标签 + 右侧计数数字 |
| 高度 | 固定行高                       |

| 状态     | 视觉表现                                                 |
| -------- | -------------------------------------------------------- |
| 默认     | 无背景                                                   |
| 悬停     | 半透明背景填充                                           |
| 选中     | 强调色背景填充，文字和图标高亮                           |
| 磁性吸附 | **拖拽物靠近时，图标产生 <4px 的位移偏移感并伴随微缩放** |
| 拖拽悬停 | 梗图从主区域拖到此项上时，出现高亮发光边框               |
| 折叠模式 | 仅显示图标，文字标签隐藏                                 |

## 反馈类组件

### Toast 轻量通知

操作完成后短暂弹出的反馈提示。

| 属性 | 规格                                                                   |
| ---- | ---------------------------------------------------------------------- |
| 位置 | 屏幕右下角弹出                                                         |
| 形状 | 圆角矩形，磨砂玻璃背景                                                 |
| 时长 | 默认 3 秒后自动消失                                                    |
| 类型 | 成功（绿色图标）/ 警告（黄色图标）/ 错误（红色图标）/ 信息（蓝色图标） |

| 状态 | 视觉动效          |
| ---- | ----------------- |
| 出现 | 从右侧滑入 + 淡入 |
| 消失 | 淡出 + 向右滑出   |

**特殊 Toast**：移动到回收站时，Toast 内附带"撤销"按钮（点击后取消删除操作）。

---

### NotificationBeacon 通知指示灯

底部状态栏最右侧的通知状态圆点。

| 属性 | 规格             |
| ---- | ---------------- |
| 形状 | 小号正圆形       |
| 位置 | 底部状态栏最右端 |

| 状态       | 视觉表现                   |
| ---------- | -------------------------- |
| 无通知     | 绿色圆点                   |
| 信息级通知 | 蓝色圆点                   |
| 警告级通知 | 黄色圆点                   |
| 错误级通知 | 红色圆点                   |
| 有未读时   | 圆点带呼吸动画（缓慢闪烁） |
| 点击       | 展开通知面板               |

---

### ProgressBar 进度条

底部状态栏中间的任务进度展示。

| 属性   | 规格                                           |
| ------ | ---------------------------------------------- |
| 形状   | 圆角细条                                       |
| 可见性 | 仅在有后台任务运行时显示，无任务时隐藏         |
| 内容   | 进度条 + 右侧文字描述（如"OCR 处理中 45/200"） |

| 状态   | 视觉表现                                       |
| ------ | ---------------------------------------------- |
| 进行中 | 按进度比例填充强调色                           |
| 完成   | **触发 Shine Overflow 光效扫过**，随后淡出消失 |
| 不确定 | 无精确进度时显示循环扫光动画                   |

---

### EmptyState 空状态占位

当画廊区域或特定视图无内容时的占位展示。

| 属性 | 规格                             |
| ---- | -------------------------------- |
| 位置 | 中间主区域居中                   |
| 内容 | 插图 + 引导文案 + 可选的操作按钮 |

| 场景       | 文案示例                       | 操作按钮   |
| ---------- | ------------------------------ | ---------- |
| 图库空     | "还没有梗图，导入你的第一张！" | "导入梗图" |
| 搜索无结果 | "没有找到匹配的梗图"           | "清除搜索" |
| 回收站空   | "回收站是空的"                 | —          |
| 未标签为空 | "所有梗图都已打上标签 🎉"       | —          |

---

### FloatActionBar 浮动操作条 [NEW]

多选模式下出现在视图底部的辅助操作栏。

| 属性 | 规格                                                           |
| ---- | -------------------------------------------------------------- |
| 背景 | 强力磨砂玻璃 (Glassmorphism)，带外发光或柔和阴影以区分背景卡片 |
| 形状 | 胶囊形（全圆角）                                               |
| 按钮 | 紧凑型圆形或圆角矩形图标按钮，带文字标签                       |

| 交互         | 表现                                             |
| ------------ | ------------------------------------------------ |
| 出现         | 向上平滑弹起并淡入 (**Elastic Overshoot Slide**) |
| 点击操作     | 对应按钮执行动作，FAB 保持显示                   |
| 批量导出完成 | **触发缩略图向目标方向飞出的粒子飞散动画**       |
| 取消选择     | 向下弹回消失                                     |

## 菜单类组件

### DropdownMenu 下拉菜单

PlusButton 点击后弹出的导入操作菜单。

| 属性 | 规格                                  |
| ---- | ------------------------------------- |
| 触发 | 点击 PlusButton                       |
| 位置 | 按钮正下方，自动避免超出窗口边界      |
| 形状 | 圆角矩形，磨砂玻璃背景，带轻微阴影    |
| 关闭 | 选择菜单项 / 点击菜单外部 / 按 Esc 键 |

| 菜单项       | 图标      | 说明                     |
| ------------ | --------- | ------------------------ |
| 快捷导入     | import    | 弹出居中拖拽导入窗口     |
| 从剪贴板导入 | clipboard | 直接读取剪贴板图片并导入 |
| 从文件导入   | file      | 弹出系统文件选择器       |
| 从 URL 导入  | url       | 弹出 URL 输入对话框      |

---

### ContextMenu 上下文菜单

右键梗图或点击三点按钮时弹出的操作菜单。

| 属性 | 规格                                   |
| ---- | -------------------------------------- |
| 触发 | 右键点击梗图 / 点击悬停时的 ··· 按钮   |
| 位置 | 鼠标点击位置或按钮旁，自动避免超出窗口 |
| 形状 | 圆角矩形，磨砂玻璃背景，带轻微阴影     |
| 关闭 | 选择菜单项 / 点击菜单外部 / 按 Esc 键  |

| 菜单项        | 图标      | 说明                           |
| ------------- | --------- | ------------------------------ |
| 复制到剪贴板  | clipboard | 将梗图写入系统剪贴板           |
| 导出          | save      | 弹出另存为对话框               |
| 编辑详情/标签 | tags      | 唤出并聚焦右侧面板             |
| 查看原图      | view      | 打开灯箱预览                   |
| 移动到        | move      | 展开子菜单，列出所有分类文件夹 |
| 移动到回收站  | delete    | 移入回收站 + 弹出撤销 Toast    |

---

| 位置 | 父菜单项右侧展开                      |
| 内容 | 列出所有来源分类文件夹                |
| 形状 | 与 ContextMenu 一致的圆角矩形磨砂玻璃 |

### MoreButton 三点设置按钮

梗图卡片悬停时右下角浮现的操作入口。

| ------ | ----------------------------------- |
